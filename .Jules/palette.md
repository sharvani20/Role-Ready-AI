## 2026-03-31 - Accessible Modal Overlays & File Upload Controls
**Learning:** Modal components built with custom backdrops often lack keyboard dismissability (`Escape` key), backdrop click handlers, explicit ARIA dialog roles (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`), and visible close buttons. Additionally, hidden file inputs inside drag-and-drop labels need `sr-only` positioning rather than `display: none` / `hidden` to maintain full accessibility for screen reader users and maintain explicit label associations (`htmlFor` and `id`).
**Action:** When creating or editing modals, always include an accessible close `<button>` with `type="button"` and `aria-label`, handle `Escape` keypress, support backdrop click dismissal, attach `role="dialog"` attributes, and link labels using `htmlFor` with `sr-only` inputs.
